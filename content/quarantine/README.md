# Quarantined content

Images moved out of `artifacts/glamr/public/` because they may infringe copyright or publicity rights (real people, press photos, artwork). They're kept here, not deleted, so they can be reviewed. This folder isn't deployed.

See `docs/content-rights.md` for the reason each file was moved. If a file turns out to be licensed, move it back to `artifacts/glamr/public/looks/` and run `pnpm --filter @workspace/glamr run regen:images`.
